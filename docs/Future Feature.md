# Future Features

用于持续记录未来可加入 USS Race Tracker 的想法。此文档是功能备忘录，不代表已实现或已排入开发计划。

## 1. AGN 达标成绩对照

记录日期：2026-10-29。状态：待调研、待实现。

希望在运动员资料或成绩页面中，直观看到当前成绩是否达到目标年份 **Age Group Nationals（AGN）** 的 qualifying times。

- 按年份／赛季收集官方 AGN 资格规则及达标时间，保留规则来源和版本；历史判断使用对应年份的规则。
- 根据该届比赛适用的参赛年龄／年龄组匹配标准。标准是否还区分性别、距离、short track / long track 等条件，实施前查证。
- 对照适用的有效成绩，清楚显示是否达到时间标准、对应标准及差距，并可查看采用的成绩与规则来源。
- 若年龄只有推算范围，或规则、成绩信息不足，明确显示待确认，不自动认定已达标或未达标。

实施前需确认：各年度官方标准的位置、适用年龄规则、成绩有效期、认可赛事，以及多个距离之间的达标条件。达到时间标准与完整参赛资格的关系也需按当届规则核实。

## 2. PDF 晋级标记的提取与明显展示

记录日期：2026-10-29。状态：待样本核实、待实现。

比赛 PDF 的逐场成绩中可能带有 `Q` 或其他 qualification／晋级 indicator。希望在网页成绩中明显显示运动员是否晋级，以及晋级到哪个阶段，例如 semi-final。

- 提取并保留原始标记，与对应比赛、距离、轮次、场次及运动员成绩关联，保留 PDF 来源页码。
- 根据该赛事的图例和晋级规则解释标记，不能仅凭字母猜测含义；不同赛事的标记可能不同。
- 在成绩表或详情中使用醒目的英文文字／徽标表达晋级状态；不能只靠颜色区分。
- 来源能确认时，显示下一阶段或分组，例如 `Qualified for semifinal`；含义不明时保留原始标记并标注待确认。
- 缺少标记时，先确认来源规则和提取完整性，再判断是否未晋级。

待确认：用户提到的 “Group A” 与晋级的关系，可能涉及晋级到 A 组或 A 组决赛；需结合具体 PDF 的标记、轮次和分组说明核实，暂不固定解释。用户口述的 “QQQ” 暂按 `Q` 一类标记记录，具体形式以原始 PDF 为准。
